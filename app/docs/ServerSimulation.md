# Server Simulation

The Server Simulation enhances the `NetworkNode` representation with real-time, dynamic data.

Features:
- Live tracking of RAM usage, Storage capacity, and running processes.
- Dynamic firewall status based on organizational security levels.
- Reflection of incident impacts (e.g., degraded performance during a DDOS attack).

This simulation is exposed to the player via the `Browser` app (Server Inspector view) and terminal commands.
