# Shadow Exchange Marketplace (v1.4.0)

## Overview
The Shadow Exchange (`darkmarket.onion`) provides illegal software, corporate access credentials, zero-day exploits, and encrypted hardware tools.

## Item Categories
- **Exploit Payloads**: Zero-day rootkits, neural bypass chips, buffer overflow injectors.
- **Corporate Credentials**: Leaked API keys, employee VPN tokens, database dumps.
- **Hardware & Relays**: Encrypted VPN transceivers, anonymizing exit node tokens.
- **Security Tools**: Cryptographic crackers, PGP key generators, trace suppressors.

## Buying Mechanics
- **Credits Deducted**: Buying an item deducts credits from player balance via `OnionNetworkEngine.buyMarketItem(id)`.
- **Seller Reputation**: Items display seller ratings (1.0 to 5.0 stars) and availability status.
- **Notification**: Emits system notification upon successful or failed purchase.
