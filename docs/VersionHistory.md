# Version History

## v0.8.0 - ONION NETWORK (2026-07-31)
- Implemented multi-hop encrypted Onion Network circuit engine (`OnionNetworkEngine`) with relay nodes and exit routers.
- Introduced 8 indexed `.onion` hidden services (`dir.onion`, `abyss-forum.onion`, `blackvault.onion`, `darkmarket.onion`, etc.).
- Created Underground Cyber Forum engine with interactive threads, posts, replies, upvotes, and category navigation.
- Added 5 autonomous NPC digital identities with specialized knowledge domains, affiliations, and communication patterns.
- Integrated Player Reputation & Trace System with Trust, Fame, Suspicion metrics, and Community Ranks (`NOVICE` to `SHADOW_ADMIN`).
- Implemented Shadow Exchange Dark Market directory for hardware schematics, zero-day advisories, and corporate subnet maps.
- Enhanced Abyss Browser with `.onion` domain rendering, bookmark bar chips, circuit status header, and interactive forum viewer.
- Added `onion` (`darknet`, `relays`) CLI command and state persistence via `SaveManager`.

## v0.7.0 - OFFENSIVE SECURITY FRAMEWORK (2026-07-31)
- Implemented central `OffensiveSecurityFramework` engine for automated security tasks and security posture evaluation.
- Added `PortScannerEngine` for non-destructive TCP/UDP port probing and banner grabbing across corporate servers.
- Introduced `ServiceScanner` for patch compliance, configuration grading (Grade A-F), and firewall defense assessments.
- Built interactive in-game Knowledge Database Wiki (`wiki.abyss`, `sec wiki`) covering cyber security protocols and architectures.
- Added `SecurityReportGenerator` exporting markdown audit reports to `/home/operator/reports/` on AbyssFS.
- Integrated Security Control Center in Network App (Tab 4) and Security Telemetry card in System Monitor.
- Added `security` (`sec`, `scan`) CLI command in Terminal.

## v0.6.0 - CORPORATE GRID (2026-07-31)
- Populated AbyssNet with 105 corporate organizations, 2500+ servers, and 200+ data center facilities.
- Expanded Network App with Local Map, Grid Tree, Organizations Directory, and Interfaces monitor.
- Enabled corporate website browsing in Browser App.
- Added Network Infrastructure card to System Monitor.
- Fixed Terminal input cursor positioning bug.

## v0.5.0 - ABYSSNET (2026-07-31)
- Implemented virtual network engine, address generators, latency simulator, packet router, and DNS resolver.
- Added network CLI commands (`ping`, `traceroute`, `netstat`, `ipconfig`/`ifconfig`, `arp`, `nslookup`, `whois`, `route`).
- Integrated Graphical Network App and Virtual Web Browser.

## v0.4.0 - AbyssFS & Terminal Core (2026-07-30)

- Terminal Core with command execution engine and shell history.
